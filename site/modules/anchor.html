ANCHOR

Embedding security

  • Python
  • REST :8083 · gRPC :9093

Protects the vectors behind search, and checks that responses stay grounded and fair.

01 OVERVIEW

Anchor protects the embedding layer and the integrity of the output. Embeddings are made resistant to privacy attacks, and responses are measured for bias, drift and grounding.

02 WHAT IT DOES

  • Noise injection: Gaussian or Laplacian noise on embeddings, with per-tenant overrides.
  • Reconstruction resistance: raw vectors extracted from the database can't rebuild the original text.
  • Norm preservation: unit length is kept so cosine similarity still works.
  • Bias analysis in both directions using WEAT (Word Embedding Association Test).
  • Response verification: bias and stereotypes, semantic drift from the query or source, and grounding in retrieved documents.
  • Quality monitoring: tracks recall@K preservation and end-to-end response quality.

03 WHERE IT SITS

PathRole
InputAnchor-IN adds calibrated noise to embeddings at index and query time, and measures bias.
OutputAnchor-OUT verifies the response: bias, drift and grounding against the retrieved documents.

04 RUN IT

cd anchor
make install && make run   # or: make start-anchor from the repo root

Note. NATS is optional. Without it, Anchor still runs; event streaming is disabled and a warning is logged.
